# Sistema de Gestão Comercial Construex (construex_db)

## 📊 Status do Projeto
🚀 Em desenvolvimento (Etapa 5 - Homologação e Versionamento)

## 🎯 Objetivo do Software
O sistema Construex foi desenvolvido para atuar como uma aplicação desktop de gerenciamento comercial e controle de ponto de venda (PDV) focado em depósitos de materiais de construção. O software automatiza os processos de controle de estoque, cadastro de clientes, autenticação de operadores e registro de transações financeiras, mitigando falhas operacionais e garantindo a persistência de dados em tempo real.

## 💻 Tecnologias Aplicadas
* **Linguagem de Programação:** Java (JDK)
* **Interface Gráfica:** Java Swing / AWT (Desenvolvido em ambiente NetBeans IDE)
* **Banco de Dados Relacional:** MySQL Server
* **Persistência de Dados:** Driver JDBC (Java Database Connectivity)
* **Controle de Versão:** Git & GitHub

## 🛠️ Funcionalidades do Sistema (Requisitos)
* **Módulo de Autenticação (Usuários):** Tela de login segura para operadores do sistema, impedindo acessos não autorizados.
* **Módulo de Clientes:** CRUD completo (Criação, Leitura, Atualização e Exclusão) de clientes com validação de campos obrigatórios como Nome, CPF/CNPJ e Endereço.
* **Módulo de Produtos (Estoque):** Controle do catálogo de mercadorias, registrando nome do fornecedor, preço unitário de venda e saldo em estoque.
* **Módulo de Vendas (PDV):** Interface automatizada para o registro de cupons de venda, com seleção de clientes, abatimento automático de itens do estoque e cálculo do faturamento geral da empresa em tempo real.
